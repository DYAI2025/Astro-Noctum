## Stack
- Vite + React + TypeScript, Node 20+
- Supabase (auth, persistence), ElevenLabs (Levi), Three.js (rings, planetarium)
- Railway deployment, Express server (server.mjs)

---

## Nicht verhandelbare Regeln (Kurzform)

**Bugs:** Sofort fixen. Root Cause verstehen. Test zuerst (rot → grün). Dann PR.

**Tests:** Keine neue Funktionalität ohne Test. `npm run lint` + `npm test -- --run`
müssen grün sein vor jedem Commit. Kein `it.skip()` ohne Issue.

**Code-Qualität:**
- Kein `.catch(() => {})` — immer loggen oder rethrow
- Kein `@ts-ignore` ohne inline-Kommentar
- Kein TODO im Code ohne GitHub Issue

**PR-Pflicht:** Jeder Task = ein PR. Body enthält: Was, Warum, Wie getestet,
Betroffene Dateien, Issue-Referenz (`Fixes #X`).

**Commits:** `feat/fix/test/refactor/chore(scope): was — warum`

---

## Escalation — sofort stoppen wenn:
- Entscheidung nötig die Produktlogik betrifft
- `supabase-schema.sql` geändert werden müsste
- Test nach 3 Versuchen nicht grün wird
- Security-relevanter Pfad betroffen

→ GitHub Issue kommentieren: `[BLOCKED]` + Problem + Was versucht + Was gebraucht
