## Context
The user pastes PR review comments — from GitHub Copilot, human reviewers, or code review skills. They expect each finding addressed in a single commit, then pushed to the same branch.

## Your Task

Address all review findings and push the fixes.

### Steps

1. **Parse findings** — Extract each review comment:
   - File path and line number
   - The issue described
   - Any suggested fix (from Copilot or reviewer)

2. **Triage** — Group by severity:
   - **Must fix**: Type errors, bugs, security issues
   - **Should fix**: Missing error handling, inconsistent patterns
   - **Nit**: Alphabetical ordering, naming, style

3. **Fix all findings** — For each:
   - Read the file at the referenced location
   - Apply the fix (use reviewer's suggestion if correct, otherwise write your own)
   - If the reviewer's suggestion is wrong, explain why in the commit message

4. **Verify** — `npx tsc --noEmit` + `npm run test` must pass.

5. **Commit and push** — Single commit addressing all findings:
   ```
   fix(<scope>): address PR review — <summary>

   - Finding 1: <what was fixed>
   - Finding 2: <what was fixed>
   ```
   Then `git push origin <branch>`.

### Guardrails
- Address ALL findings, not just the critical ones
- If a finding is a false positive, still acknowledge it in the commit message
- Don't batch review fixes with unrelated changes
- Check if fixes need to land on the PR branch (not main)
