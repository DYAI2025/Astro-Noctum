## Context
The user reports bugs in German, often with screenshots. They expect thorough, sustainable fixes — not quick patches. The app runs on Railway and uses feature flags with localStorage overrides.

## Your Task

Diagnose and fix the reported bug(s).

### Steps

1. **Parse the report** — Read the user's German description + any screenshots. Identify:
   - Which page/component is affected
   - Expected vs actual behavior
   - Whether it's a regression (worked before) or new

2. **Trace the code path** — Starting from the route/page, follow the component tree:
   - Check feature flags (`src/lib/feature-flags.ts`) — is the feature gated?
   - Check the relevant hook/service — is data flowing correctly?
   - Check server endpoints in `server.mjs` — are proxies returning data?

3. **Reproduce locally** — If possible, identify the exact condition:
   - New user vs existing user?
   - Feature flag state?
   - API availability (BAFE, Supabase, Gemini)?

4. **Fix sustainably** — Apply the fix. The user explicitly wants "nachhaltig und robust":
   - Add fallback behavior where appropriate
   - Don't just fix the symptom — fix the root cause
   - If a feature flag is involved, verify both ON and OFF paths work

5. **Verify** — Run `npx vitest run` for affected test files, then `npm run test` for full suite.

6. **Ship** — Invoke `/ship` to commit and push.

### Guardrails
- Never dismiss CSP/CORS errors as "third-party noise" without checking if they block functionality
- Check the deployment environment (Railway) if the bug is production-only
- If multiple bugs are reported in one message, fix ALL of them before shipping
- Respond in the same language the user used (German)
