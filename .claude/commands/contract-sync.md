## Context
Astro-Noctum consumes FuFirE (BAFE) API endpoints. A copy of FuFirE's OpenAPI 3.1.0 spec is stored at `spec/fufire-openapi.json`. Contract tests in `src/__tests__/fufire-contract.test.ts` validate that our Zod schemas are compatible with FuFirE's spec.

## Your Task

Sync the OpenAPI spec from FuFirE and run contract tests to detect schema drift.

### Steps

1. **Pull latest spec** from FuFirE repo:
   ```bash
   # If FuFirE is cloned locally:
   cp /Users/benjaminpoersch/Projects/codebase/FuFirE/spec/openapi/openapi.json spec/fufire-openapi.json

   # If not cloned:
   cd /Users/benjaminpoersch/Projects/codebase && git clone https://github.com/DYAI2025/FuFirE.git --depth 1
   cp FuFirE/spec/openapi/openapi.json ../Bazodiac-WebApp/Astro-Noctum/spec/fufire-openapi.json
   ```

2. **Run contract tests**:
   ```bash
   npx vitest run src/__tests__/fufire-contract.test.ts
   ```

3. **Analyze results**:
   - All 37 tests pass → spec is compatible, no drift
   - Failures → report which schemas changed, which fields are missing/renamed

4. **If drift detected**:
   - Update our Zod schemas in `src/lib/schemas/` to match new spec
   - Update type definitions in `src/types/bafe.ts` if BAFE response shapes changed
   - Update mappers in `src/services/api.ts` if field names changed
   - Re-run contract tests until green

5. **Commit** if spec was updated:
   ```
   feat(contract): sync FuFirE OpenAPI spec — [describe changes]
   ```
