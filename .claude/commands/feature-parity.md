## Context

Bazodiac is a web + mobile app. Features built on web (`src/`) don't always exist on mobile (`apps/mobile/`) and vice versa. This skill audits the gap and brings both targets to parity.

## Your Task

Audit feature parity between web and mobile, then implement the missing pieces.

### Steps

1. **Audit web features** — Scan `src/` for all distinct features:
   - Routes in `src/router.tsx`
   - Components in `src/components/`
   - Hooks in `src/hooks/`
   - API endpoints in `server.mjs`

2. **Audit mobile features** — Scan `apps/mobile/src/` for all distinct features:
   - Screens in `src/screens/`
   - Navigation routes in `src/navigation/`
   - Hooks in `src/hooks/`

3. **Map the gap** — Build a two-column table:

   | Feature | Web | Mobile |
   |---------|-----|--------|
   | Signatur ring | V2 FusionRingCanvasV2 | SignaturCanvas (not mounted) |
   | Daily horoscope modal | DailyHoroscopeModal | useDailyHoroscope (screen?) |
   | ... | ... | ... |

4. **Present gap to user** — Show the table and ask which gaps to close. Wait for selection before proceeding.

5. **Plan the parity work** — For each selected gap, invoke `superpowers:writing-plans` with:
   - The web implementation as reference (`src/` path)
   - The mobile target path (`apps/mobile/src/`)
   - Shared package constraint: shared types go to `packages/shared/`, not duplicated

6. **Execute in parallel** — Invoke `superpowers:execute-plan` with `1. subagent` for each target. Run web and mobile agents in parallel when independent.

7. **Verify** — Web: `npm run test` + `npm run lint`. Mobile: `npx tsc --noEmit` from `apps/mobile/`.

8. **Ship** — Invoke `ship` to commit and push.

### Guardrails
- Never copy-paste web code verbatim into mobile — adapt to RN/Expo APIs
- Shared types and scoring logic go to `packages/shared/` — import from `@bazodiac/shared`
- Mobile uses AsyncStorage for caching (not localStorage)
- UI components use `src/theme.ts` COLORS constant, not Tailwind classes
- New mobile screens need to be registered in `src/navigation/RootNavigator.tsx`
- `SignaturCanvas.tsx` exists but is not mounted — check if it's ready before using it, or use the 2D bootstrap view as mobile does now
