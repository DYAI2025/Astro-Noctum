## Your Task

Read the Miro Bug-Tracker, take the top N bugs (default: 3), plan fixes, implement, code review, and ship.

### Steps

1. **Open Miro Board** via chrome automation. Navigate to the board URL. Zoom/scroll to find the BUG-TRACKER table.

2. **Extract bug details** — for each bug read: Bug-ID, Title, Priority, Status, Datei/Ort (file path), Symptom, Fix-Vorschlag.

3. **Plan fixes** — for each bug, verify the file/code referenced still exists. If the bug is already fixed (code doesn't match symptom), note it.

4. **Implement fixes** — use parallel agents for independent bugs. Each agent should:
   - Read the relevant files
   - Implement the fix following Fix-Vorschlag
   - Run `npx tsc --noEmit` to verify no type errors

5. **Code review** — invoke the code-reviewer agent on all changes. Only proceed if approved.

6. **Ship** — `git add` specific files, commit with `fix(AN-BUG-XX):` prefix, push to main.

7. **Update Miro Board** — navigate back to the board, click each bug's Status cell, change from "Offen" to "Gefixed".

### Guardrails
- Always verify bug still exists before fixing (check current code state)
- Run TypeScript check after each fix
- Use parallel agents for independent bugs
- Commit per-bug or batched — never mix unrelated changes
- If a bug requires external access (BAFE, FuFirE, Supabase admin), note it and ask user
