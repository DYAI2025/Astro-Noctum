## Context

iOS simulator screenshots arrive as temp paths like `/var/folders/.../simulator_screenshot_*.png`. Crashes manifest as dark screens, blank content, navigation jumping back, or stale Supabase placeholder data. All fixes live in `apps/mobile/src/`. The build command is `npx expo run:ios` (from `apps/mobile/`).

## Your Task

Diagnose and fix the iOS simulator crash or regression.

### Steps

1. **Read the screenshot** — If a path is provided, use the Read tool on the image. Identify:
   - Is it a full crash (dark/black screen)?
   - Is it a layout regression (wrong content, navigation issue)?
   - Is it data-related (Supabase placeholder, empty state)?

2. **Read the error description** — The user's message (often in German) names what went wrong. Combine with the screenshot to pinpoint the screen and component.

3. **Locate the broken code** — Search `apps/mobile/src/` for the relevant screen/component:
   - Navigation issues → `src/navigation/`
   - Screen content → `src/screens/`
   - Data fetching → `src/hooks/` or `src/lib/`
   - Quiz → `src/components/QuizRenderer.tsx`

4. **Check TypeScript** — Run `cd apps/mobile && npx tsc --noEmit` to catch type errors before touching code.

5. **Fix** — Make the minimal change. Prefer root-cause fixes over defensive null-checks. If the fix is non-trivial, invoke `superpowers:writing-plans` first for a step-by-step plan.

6. **Verify** — Run `cd apps/mobile && npx tsc --noEmit` again. If there is a simulator running, the user will retest manually.

7. **Ship** — Invoke `ship` to commit and push with `fix(mobile): ...` commit message.

### Guardrails
- Never import from `src/` (web) into `apps/mobile/src/` — use `@bazodiac/shared` for shared code
- AsyncStorage keys must be consistent — check `src/lib/offlineQueue.ts` + `src/hooks/useBootstrapSignatur.ts` for existing key conventions
- ElevenLabs voice screen uses a WebView — crash there is often a URL/auth issue, not a RN bug
- Supabase placeholder data usually means the hook fetched before auth was ready — add `if (!user) return` guard
