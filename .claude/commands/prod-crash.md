## Context

Live crashes on bazodiac.space manifest as: blank screen, CSP directive errors, Railway
build failures, FuFirE 422/500 errors, Supabase auth failures, onboarding not starting,
or "Renderer-Fehler. Fallback aktiv." The user pastes a console snippet, Railway log, or
describes the symptom. All fixes live in `src/` or `server.mjs`. The test command is
`npx vitest run`. Deploy is Railway (auto-deploy on push to main).

## Your Task

Diagnose and fix the live web app crash or regression as fast as possible.

### Steps

1. **Parse the error** — Read what the user pasted. Classify it:
   - **CSP / header error** → `server.mjs` Content-Security-Policy block or `index.html`
   - **FuFirE 422/500** → `src/services/api.ts` payload mismatch or BAFE schema change
   - **Supabase auth / RLS error** → `src/lib/supabase.ts` or `src/services/supabase.ts`
   - **Onboarding not starting / blank screen** → `src/App.tsx` state machine or feature flags
   - **Renderer-Fehler / Fallback aktiv** → `src/hooks/useFusionSignal.ts` or `server.mjs` transit-state proxy
   - **Railway build failure** → `nixpacks.toml`, `package.json` scripts, TypeScript errors
   - **"Missing VITE_*"** → env var not set in Railway; inform user to add it in Railway dashboard

2. **Locate the broken code** — Grep for the error string or trace from the entry point:
   - Network errors → `server.mjs` proxy routes
   - Client exceptions → `src/` component or hook
   - Build errors → TypeScript (`npx tsc --noEmit`)

3. **Check TypeScript** — Run `npx tsc --noEmit 2>&1 | head -20` before touching code.

4. **Fix** — Minimal targeted change. Prefer root-cause fixes over try/catch silencing.
   If non-trivial, invoke `/writing-plans` first.

5. **Run tests** — `npx vitest run 2>&1 | tail -5`. All must pass before shipping.

6. **Ship** — Invoke `/ship` with `fix: ...` commit message. Railway auto-deploys on push.

### Guardrails
- Never silence errors with empty catch blocks — Railway logs are the only visibility into prod
- CSP errors: always add the exact domain to the directive in `server.mjs`; never use wildcards for script-src
- FuFirE 422: check the payload field names first — BAFE renames fields without notice
  (e.g. `date` → `local_datetime`). Cross-check with `src/services/api.ts` mappers.
- Feature flags: if onboarding vanished, check `localStorage.getItem('ff_signature_onboarding_v1')`
  — it may be force-disabled. Default is `true`.
- `VITE_*` env vars missing at runtime: these must be set in Railway → Variables, not just `.env.local`
- Never commit `.env` or `.env.local` — remind user to set secrets in Railway dashboard
- Missing Railway env var → user must add it; we cannot push it via code
