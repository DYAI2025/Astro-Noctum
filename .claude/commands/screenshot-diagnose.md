## Context
User shares a screenshot showing a UI bug on bazodiac.space or localhost. Diagnose the visual issue, find the code responsible, fix it, and verify.

## Your Task

Analyze the screenshot, identify the bug, find the responsible code, fix it, and verify.

### Steps

1. **Analyze screenshot** — identify the visual issue (layout broken, element missing, wrong text, overlay blocking, etc.)

2. **Identify affected component** — based on the visible UI elements, determine which React component renders this area. Use the route/page context + component tree knowledge from CLAUDE.md.

3. **Inspect live site** (if available) — use chrome automation to:
   - Navigate to the relevant page
   - Run JavaScript to inspect DOM state, z-index layers, visibility, computed styles
   - Check console for errors

4. **Find root cause in code** — search the identified component and its parents for:
   - CSS/Tailwind issues (z-index, overflow, display, pointer-events)
   - Conditional rendering bugs (wrong state check, missing data)
   - Overlay/modal conflicts (fixed positioning, body scroll lock)

5. **Fix** — make the minimal change. Run `npx tsc --noEmit`.

6. **Verify** — if browser is available, reload and check the fix visually. Take a screenshot for comparison.

### Guardrails
- Always check for overlapping fixed/absolute positioned elements (TourOverlay, modals, etc.)
- Check `body.style.overflow` and `pointer-events` — common culprits for "button not clickable"
- German UI text — use `t()` translations, never hardcode language
- Don't fix unrelated issues found during investigation — note them for later
