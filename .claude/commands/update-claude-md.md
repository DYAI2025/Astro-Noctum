## Context
The `### Current State` section in `CLAUDE.md` under `## Project Overview` is the authoritative project summary. It gets stale as tasks complete and decisions are added across sessions.

## Your Task

Refresh the Current State paragraph in CLAUDE.md with actual data from the codebase.

### Steps

1. **Count tasks by status:**
   ```bash
   grep -cE '\| Done ' 3-code/tasks.md
   grep -cE '\| Todo ' 3-code/tasks.md
   grep -cE '\| In Progress ' 3-code/tasks.md
   grep -cE '\| Cancelled ' 3-code/tasks.md
   ```

2. **Count decisions:**
   ```bash
   ls 2-design/decisions/DEC-*.md | grep -v history | wc -l
   ```

3. **Count requirements by status:**
   ```bash
   grep -c "Status.*Implemented" 1-objectives/requirements/REQ-*.md
   grep -c "Status.*Approved" 1-objectives/requirements/REQ-*.md
   grep -c "Status.*Draft" 1-objectives/requirements/REQ-*.md
   ```

4. **Identify completed sprints** — scan tasks.md for sprints where all tasks are Done/Cancelled

5. **Identify active sprint** — the earliest sprint with remaining Todo tasks

6. **Update CLAUDE.md** — edit the Current State paragraph with:
   - Phase (always "Code")
   - Goal count and status breakdown
   - Requirement count and status breakdown
   - Constraint count
   - Assumption count
   - Decision count
   - Completed sprints list
   - Active sprint + progress
   - Task totals: Done / Total (%)
   - Date: today

7. **Also update `1-objectives/CLAUDE.objectives.md`** index rows if requirement statuses changed

### Guardrails
- Only update the Current State paragraph — do not rewrite other sections
- Use exact counts from grep, not memory
- Include the date in the update
- Do not commit — leave for user review
