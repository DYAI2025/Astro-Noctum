# CON-mobile-first-readability: Mobile-First Readability Under 10 Seconds

**Category**: Business

**Status**: Active

**Source stakeholder**: [STK-product-owner](../stakeholders.md)

## Description

All insight outputs (Vibes, Weekly Insights) must be scannable and comprehensible on a mobile screen within 10 seconds. This constrains text length, information density, and visual hierarchy. Desktop may show additional depth but the core message must be mobile-optimized.

## Rationale

The primary use case is spontaneous check-ins on mobile. Users want quick orientation, not long reads. If the insight requires scrolling or expanded reading to understand, it fails the readability test.

## Impact

- Vibes Kurzsignal: max 1 sentence
- Vibes Einflussfaktoren: max 5 items, each 2–4 words
- Weekly Insights: each area max 1 sentence + 1 tendency label
- Top-3 areas may have 1 additional sentence
- Explanation layer is opt-in (behind "Warum?" tap), not inline
- Mobile and web share identical logic but web may show denser layout
