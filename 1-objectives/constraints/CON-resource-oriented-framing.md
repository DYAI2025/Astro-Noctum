# CON-resource-oriented-framing: Resource-Oriented, Non-Fatalistic Framing

**Category**: Business

**Status**: Active

**Source stakeholder**: [STK-product-owner](../stakeholders.md)

## Description

All user-facing text — whether human-authored or AI-generated — must use possibility-oriented, resource-focused language. Insights describe tendencies, not predictions. Language like "Tendenz", "kann", "möglicherweise" is required; language like "Schicksal", "wird passieren", "du bist X" is prohibited.

## Rationale

Bazodiac is a self-reflection tool, not a fortune-telling service. Fatalistic framing creates dependency and liability. Resource-oriented language empowers users to interpret insights as one input among many.

## Impact

- Gemini prompts must include explicit framing instructions (possibility language, no diagnosis)
- Weekly Insights use "Tendenz" labels, not predictions
- Vibes output uses qualitative descriptions, not prescriptive statements
- Consistent with existing QuissMe AI Mapping Lexicon guardrails (no "you are X", always "can", "sometimes", "might")
