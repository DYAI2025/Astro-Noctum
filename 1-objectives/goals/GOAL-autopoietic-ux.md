# GOAL-autopoietic-ux: Autopoietic User Experience

**Description**: The UI adapts to the user's elemental signature through a three-layer autopoietic model. The application behaves as a biological-digital organism that breathes in resonance with its observer, evolving its interface as the user engages more deeply with their profile.

**Status**: Approved

**Priority**: Must-have

**Source stakeholder**: [STK-product-owner](../stakeholders.md)

## Success Criteria

- [ ] Obsidian Core layer is immutable — no external input (quizzes, live data, partner signals) alters the calculated signature
- [ ] Neural Myzel layer grows organically with user interaction: quiz completions, partner invites, and daily usage create new bioluminescent connections
- [ ] Bioluminescent Membrane layer adapts visually based on the user's elemental profile and interaction depth
- [ ] Navigation follows the Z-axis depth metaphor rather than horizontal scrolling
- [ ] The membrane begins conventionally (routes, buttons, scroll) and becomes more fluid as the user deepens engagement
