# US-daily-resonance-badges: Premium Resonance Badges

**Status**: Draft

**Source**: [GOAL-daily-chart-coherence-first](../goals/GOAL-daily-chart-coherence-first.md)

**Source stakeholder**: [STK-end-user](../stakeholders.md)

## User Story

As a premium user, I want to see resonance badges that show which resonance types are especially active today, so that I get a richer contextual overview of my energetic state.

## Acceptance Criteria

- [ ] `resonance_badges[]` from the Impact/Daily response are displayed only for premium-tier users
- [ ] Free-tier users see a teaser (blurred or locked badges) with a premium upgrade CTA
- [ ] Each badge displays its resonance type and intensity label
- [ ] Badges are absent from the response or hidden in the UI when the Impact block is not included
