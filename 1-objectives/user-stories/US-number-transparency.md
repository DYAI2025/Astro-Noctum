# US-number-transparency: Trusting Displayed Numbers

**Status**: Draft

**Source**: [GOAL-vibes-weekly-insights](../goals/GOAL-vibes-weekly-insights.md)

**Source stakeholder**: [STK-end-user](../stakeholders.md)

## User Story

As a user, I want to understand every number I see so that I can trust the information.

## Acceptance Criteria

- [ ] Every displayed number has at least one of: explanation, comparison basis, or meaning description
- [ ] No isolated percentages or scores appear in the UI
- [ ] If a number cannot be explained → it is removed from the UI
- [ ] Tooltips or inline descriptions provide context for numerical values
