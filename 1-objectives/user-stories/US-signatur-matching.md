# US-signatur-matching: Dual-Ring Compatibility Overlay

**Status**: Draft

**Source**: [GOAL-signatur-phase3-matching](../goals/GOAL-signatur-phase3-matching.md)

**Source stakeholder**: [STK-end-user](../stakeholders.md)

## User Story

As a user, I want to overlay my Signatur with another person's and receive a dimensional compatibility score, so that I can understand our relationship dynamic using frequency-based geometry rather than conventional horoscope questionnaires.

## Acceptance Criteria

- [ ] Two Signaturs can be rendered overlaid as a Dual-Ring visualization; overlapping areas show resonance, gaps show growth fields
- [ ] A compatibility score is derived from density field cosine similarity with dimensional breakdown (e.g., "Kreativitäts-Achse geteilt, Assertion-Achse ergänzend")
- [ ] Team compatibility (N ≤ 12 users) produces an N×N matrix with ensemble strength and blind-spot analysis
