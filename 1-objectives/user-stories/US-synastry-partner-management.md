# US-synastry-partner-management: Partner Profile Management

**Status**: Draft

**Source**: [GOAL-synastry-compatibility](../goals/GOAL-synastry-compatibility.md)

**Source stakeholder**: [STK-end-user](../stakeholders.md)

## User Story

As a user, I want to add, view, and delete partner profiles with birth data, so that I can initiate a synastry analysis for any person without requiring them to have a Bazodiac account.

## Acceptance Criteria

- [ ] A partner profile stores: display name, birth date, birth time, birth place (coordinates + timezone)
- [ ] Multiple partner profiles can exist per user
- [ ] A partner profile can be deleted; deletion removes all associated synastry results
- [ ] Partner data is scoped to the authenticated user (RLS enforced)
