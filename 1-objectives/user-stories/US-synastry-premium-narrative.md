# US-synastry-premium-narrative: Premium Synastry Narrative

**Status**: Draft

**Source**: [GOAL-synastry-compatibility](../goals/GOAL-synastry-compatibility.md)

**Source stakeholder**: [STK-end-user](../stakeholders.md)

## User Story

As a premium user, I want to receive a Gemini-generated narrative interpretation of my synastry aspects, so that I get a deeper, personalised understanding of the relationship dynamics beyond the raw aspect grid.

## Acceptance Criteria

- [ ] Premium users receive a Gemini-generated German narrative referencing specific aspects from the interaspect data
- [ ] Free users see a template-based summary (not Gemini-generated) plus a premium upgrade CTA
- [ ] Narrative text is in German and follows CON-resource-oriented-framing
- [ ] Server-side tier check enforces the premium gate (DEC-conversion-tiers) before triggering Gemini
