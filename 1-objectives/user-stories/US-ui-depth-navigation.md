# US-ui-depth-navigation: Z-Axis Depth Navigation

**Status**: Draft

**Source**: [GOAL-autopoietic-ux](../goals/GOAL-autopoietic-ux.md)

**Source stakeholder**: [STK-end-user](../stakeholders.md)

## User Story

As a user, I want to navigate between the Dashboard (surface), Signatur (mid-layer), and detail views (core) using visual depth cues, so that the information hierarchy feels like moving inward rather than switching between flat pages.

## Acceptance Criteria

- [ ] Each navigation level has a defined depth: Dashboard = surface, Signatur = mid, detail views = core
- [ ] Transitions between depths use animated depth cues (not a flat page swap)
- [ ] New users see conventional navigation affordances (buttons, scrolling)
- [ ] Engaged users (cluster completion threshold reached) see more fluid, gesture-based affordances
- [ ] Depth navigation is testable: a given route maps to a specific depth level
