# US-vibes-explainability: Understanding Why I See This Vibe

**Status**: Draft

**Source**: [GOAL-vibes-weekly-insights](../goals/GOAL-vibes-weekly-insights.md)

**Source stakeholder**: [STK-end-user](../stakeholders.md)

## User Story

As a user, I want to understand why I see this particular vibe so that I can trust the insight.

## Acceptance Criteria

- [ ] "Warum sehe ich das?" or "Details anzeigen" button is available on every Vibe result
- [ ] Explanation references: current constellation (simplified) and personal Signatur
- [ ] Explanation is understandable, not technically overloaded
- [ ] No black-box statements without justification
