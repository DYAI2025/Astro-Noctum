# US-vibes-on-demand: Spontaneous Vibe Check

**Status**: Draft

**Source**: [GOAL-vibes-weekly-insights](../goals/GOAL-vibes-weekly-insights.md)

**Source stakeholder**: [STK-end-user](../stakeholders.md)

## User Story

As a user, I want to spontaneously see my current energetic state so that I can better assess my next few hours.

## Acceptance Criteria

- [ ] A clear "Vibe abrufen" button exists on the Dashboard
- [ ] Result appears immediately (technically <2s, UX-comprehensible <10s)
- [ ] Insight explicitly references "the next few hours" (2–3h horizon)
- [ ] Output contains: 1 Kurzsignal, 3–5 Einflussfaktoren, 1 Erklärung
- [ ] No number visible without explanation
- [ ] Output is deterministic: same user + same timestamp = same result
