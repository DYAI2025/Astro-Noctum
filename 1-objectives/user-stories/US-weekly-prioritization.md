# US-weekly-prioritization: Weekly Top-3 Life Area Focus

**Status**: Draft

**Source**: [GOAL-vibes-weekly-insights](../goals/GOAL-vibes-weekly-insights.md)

**Source stakeholder**: [STK-end-user](../stakeholders.md)

## User Story

As a user, I want to see which life areas are especially relevant this week so that I can set priorities.

## Acceptance Criteria

- [ ] Top 3 areas are visually highlighted (larger, bolder, or with accent color)
- [ ] Top areas contain additional depth (1 extra sentence or explanation)
- [ ] Remaining areas are consciously reduced (shorter, less prominent)
- [ ] Prioritization is derived from Signatur + transit data, not random
