## Status Legend

| `Todo` | Not started |
| `In Progress` | Currently being worked on |
| `Blocked` | Waiting on a dependency or decision (reason **must** be noted in the Notes column) |

| Priority | Meaning |

| `P2` | Implements a Should-have goal |
