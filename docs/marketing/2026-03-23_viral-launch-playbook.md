## 3. TikTok Strategie (Primary Channel)

### Warum TikTok first?
Co-Star hat 23.8M TikTok-Likes bei 357K Followern = 62.5K avg Likes/Video. Astro-Content geht auf TikTok viral wie kaum ein anderes Thema. Und: Bazodiac hat etwas, das Co-Star NICHT hat — eine einzigartige, animierte Visualisierung.

### Posting Schedule: 1-2x pro Tag

### Video-Formate (mit Hooks)

#### Format 1: "Dein Tagesmeister als..." (Identity Hook)
```
Hook (0-1s): "Dein chinesischer TAGESMEISTER als Kaffeegetränk"
Visual: Text-Overlay mit BaZi-Element-Icons
Content (1-15s): Schnelle Liste:
  Yang Holz = Schwarzer Kaffee (stark, direkt)
  Yin Feuer = Chai Latte (warm, einladend)
  Yang Wasser = Cold Brew (tiefgründig, ruhig)
  ...
CTA (15-18s): "Welcher bist du? Link in Bio"
Sound: Trending
```
**Varianten:** als Filmgenre, als Urlaubsziel, als Spotify-Playlist, als Emoji-Kombination, als Toxic Trait, als Love Language

#### Format 2: "Was dein Sternzeichen NICHT über dich verrät" (Education + Curiosity)
```
Hook (0-2s): "Dein Sternzeichen ist nur 30% von dir."
Visual: Split-Screen — Zodiac vs. BaZi Chart
Content (2-20s): "Die anderen 70%? Dein BaZi.
  Dein Tagesmeister zeigt dein wahres Ich.
  Dein WuXing-Element zeigt deine Energie.
  Die Fusion zeigt das Gesamtbild."
CTA (20-25s): "Finde deine Signatur — Link in Bio"
Sound: Mysterious/atmospheric
```

#### Format 3: "Watch Your Cosmic Signature Form" (Visual Hook)
```
Hook (0-1s): Schwarzer Bildschirm → goldener Partikel-Burst
Visual: Screen-Recording der Signatur-Morph-Animation
  - Neutrale Partikelwolke
  - Geburtsdaten fliegen ein (Text-Overlay: "21.03.2000, Berlin")

  - Finale Form pulsiert
```

**Warum viral:** Visuell hypnotisch, ASMR-ähnlich, "satisfying video" Kategorie. Shareable weil jeder wissen will wie seine eigene aussieht.

#### Format 4: "POV: Du findest raus dass du mehr bist als dein Sternzeichen" (Trend-Format)
