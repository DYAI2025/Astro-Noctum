**Files:**
- Modify: `src/services/supabase.ts` (add `deleteAstroProfile`)
- Modify: `src/hooks/useAstroProfile.ts:88-94` (call delete on parse failure)
- Test: `src/__tests__/useAstroProfile.test.ts`

### Step 3: Add `deleteAstroProfile` to supabase service

```typescript
export async function deleteAstroProfile(userId: string): Promise<void> {
  const { error } = await supabase
    .from("astro_profiles")
    .delete()
    .eq("user_id", userId);
  if (error) console.error("deleteAstroProfile error:", error);
}
```
