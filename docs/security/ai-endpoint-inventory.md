# AI Endpoint Inventory

> Snapshot inventory of every Bazodiac backend route that calls a Gemini /
> OpenRouter model, plus its current protections. Used by the backend
> hardening sprint (`docs/plans/2026-05-06-backend-hardening.md`).
>
> **Source:** `server.mjs` (commit `7b3717d` and forward).

## Status legend

- **Auth before**: how the route is gated *before* hitting the AI provider.
  - `public` — no authentication. Anyone on the internet can call.
  - `user-auth` — Supabase JWT verified via `requireUserAuth`.
  - `tool-auth` — ElevenLabs `Bearer` secret verified inline.
- **Cost risk**: `low` (1 short prompt, no external lookups), `med` (1–2 prompts
  with some external lookups), `high` (large prompts or chain-of-prompts that
  can be triggered without rate limit).
- **Protection**: comma-separated list of active controls.
  - `Auth` (Supabase JWT), `ToolAuth` (Bearer secret), `Validation` (Zod),
    `Quota` (per-user AI quota), `RateLimit-User`, `RateLimit-IP`,
    `RateLimit-Global` (the legacy 2000/15min `apiLimiter`),
    `PayloadGuard` (50kb / 25kb cap before parser), `OutputValidation`.

## Key changes (this sprint)

**`/api/interpret`** and **`/api/analyze/conversation`** were `public` until
commit `7b3717d`. They are now `user-auth` and gated by the AI router
mounted in `server.mjs:342`. The original handlers (lines 5852, 5945) execute
unchanged via Express `next('route')` after the new middleware chain.

## Open follow-ups

1. **AI quota** (Task 11) is not yet wired to any route. When the
   `aiQuota.service.mjs` lands, attach `reserveAiQuota` to `/api/interpret`
   and `/api/analyze/conversation` first, then expand to
   `/api/experience/*` and `/api/agent/*`.
2. **`/api/horoscope/daily/:userId`** is GET-public and uses a 60s
   server-side cache. Low-cost per call, but unauthenticated traffic could
   still hammer the cache layer. Add IP rate-limit before next sprint.
3. **ElevenLabs `tool-auth` routes** (`/api/agent/*`) verify the Bearer
   secret inline rather than via a shared middleware. Task 15 extracts this
   into `server/middleware/elevenLabsAuth.mjs` with `crypto.timingSafeEqual`.
4. **Output validation**: none of the AI routes parse the model response
   against a schema. Tasks 7–9 of the original brief (output validation,
   provider error mapping) are deferred to a follow-up sprint.
5. **`/api/synastry`**: no AI rate-limit beyond the global 2000/15min
   bucket. Premium-only gating limits abuse but does not bound provider
   spend per premium user. Add `aiUserRateLimit('premium')` next.

## Reading this document

This file is *generated by hand* during route audits. When new AI-using
routes are added (or auth status changes), update the table in the same
PR. CI does not enforce consistency yet — see `scripts/check-secret-leak.mjs`
(Task 19) for the only automated check covering the AI surface.
