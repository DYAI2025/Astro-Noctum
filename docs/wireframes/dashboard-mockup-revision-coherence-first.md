# Dashboard Mockup Revision — Coherence First

## Intent

Refine the current dashboard mockup so that the user sees the **coherence value first** and understands immediately which live astrological forces are shaping it.

The dashboard should still follow the brand design and brand voice, but the hierarchy changes:

1. Coherence comes first
2. Active planetary influences come directly below
3. Daily interpretation remains visible as a supporting live layer
4. Astro agents stay as the interpretation bridge
5. Blueprint remains in its current lower position for now
6. Stable natal reference values remain below as fixed interpretive basis

## Revised layout description

### 1. Coherence hero at the very top

The first major content block directly below the page header is the **Coherence Index**.

This block must:

- be the first thing the user reads
- present the coherence value as an **orienting live value**, not as praise or blame
- explain in one short sentence what is currently shaping the value
- show the user that the value is derived from present-day inputs such as:
  - cosmic weather
  - active transits
  - current day pulse / daily field
  - contribution-sensitive user state

### 2. Coherence driver strip inside the same area

Inside or directly attached to the coherence block, show a compact driver layer:

- geomagnetic activity
- solar pressure
- transit pressure / transit resonance
- current daily mode or day-pulse state

These must be expressed in astrological language, not as abstract dashboard metrics.

The user should understand:

- what is active now
- what contributes to the coherence state
- which forces are calm, amplifying, or tense

### 3. Planet section directly below coherence

The planet cards move below the coherence block.

Important rules:

- do not show a fixed set of planets
- only show planets that currently have meaningful transit relevance for this user
- relevance must be determined in relation to the user's natal chart
- each planet card must explain the influence in immediate natural language

Each active planet card should show:

- planet name
- current aspect
- natal-chart reference context
- the activated quality in plain language
- what kind of influence this creates for the user right now

Example tone:

- "Mars activates your natal assertion axis — clearer boundaries, stronger outward drive"
- "Venus softens your emotional field through a harmonious contact to your natal Moon"
- "Saturn increases pressure on your structure theme — discipline becomes more visible than flow"

### 4. Daily pulse remains as live interpretation support

Below the planet section, keep the Daily Pulse area as the short narrative layer that translates the current field into a readable daily orientation.

Its role is:

- not to replace the coherence value
- not to replace the planet cards
- but to synthesize the live field into one compact daily reading

### 5. Astro agents remain without portraits

Levi and Eve stay below the volatile live section as the interpretation bridge.

Rules:

- no portrait images
- text-led brand presentation only
- they visually read as advisory / interpretive tools, not as the primary daily signal

### 6. Blueprint stays where it currently sits

Do not move the Blueprint in this iteration.

Keep it below the Astro agents for now.

### 7. Stable natal values remain correct and lower on the page

The fixed values remain in the lower dashboard area:

- Sun Sign
- Moon Sign
- Ascendant
- BaZi pillars
- Wu-Xing elements

These remain expandable and explanatory, but clearly read as stable interpretive basis rather than live daily drivers.

## Summary of the revised reading order

1. Coherence Index
2. Coherence drivers
3. Active natal-context planet influences
4. Daily Pulse
5. Astro agents
6. Blueprint
7. Stable natal reference values
