# Hypothesis Planet Correlation Rules

Status: DRAFT + TO_BE_ADDED_FROM_CODE

## Zweck

Definiert, wie Planetenkontexte mit den sieben Deep-Dive-Angelpunkten korrelieren.

## Sieben Angelpunkte

- self_image
- protection_strategy
- relationship_mode
- conflict_boundary_mode
- interpretation_pattern
- development_longing
- shadow_deviation_point

## Grundregel

Im Deep Dive muss der aktive Planet mindestens zwei passende Hypothesen beruehren. Die Auswahl erfolgt anhand:

1. hoher Resonanz zum aktiven Planeten im Natal-Chart,
2. offener Abweichungskandidaten,
3. letzter Gespraeche,
4. niedrigem Verdichtungsgrad,
5. robuster Hypothesen, die differenziert werden koennen.

## Beispielhafte Standard-Affinitäten

Diese Beispiele sind konzeptionell, nicht final:

- Sonne -> self_image, development_longing, shadow_deviation_point
- Mond -> protection_strategy, relationship_mode, self_image
- Merkur -> interpretation_pattern, self_image, protection_strategy
- Venus -> relationship_mode, self_image, development_longing
- Mars -> conflict_boundary_mode, protection_strategy, shadow_deviation_point
- Jupiter -> development_longing, interpretation_pattern, self_image
- Saturn -> protection_strategy, conflict_boundary_mode, development_longing
- Uranus -> shadow_deviation_point, development_longing, relationship_mode
- Neptun -> interpretation_pattern, protection_strategy, relationship_mode
- Pluto -> shadow_deviation_point, protection_strategy, conflict_boundary_mode
