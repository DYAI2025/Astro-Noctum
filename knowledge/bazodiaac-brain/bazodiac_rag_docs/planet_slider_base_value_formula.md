# Planet Slider Base Value Formula

Status: TO_BE_ADDED_FROM_CODE

## Zweck

Beschreibt, wie der natale Basiswert eines Planeten-Sliders berechnet wird.

## Benötigte Informationen

- Eingabedaten aus Natal-Chart.
- Gewichtung von Zeichen, Haus, Aspekten, BaZi/WuXing-Fusion.
- Normalisierung auf Slider-Wert.
- Umgang mit fehlenden Daten.
- Confidence-Wert.

## Erwartete Dokumentation

```text
base_value = TO_BE_ADDED_FROM_CODE
```

## Agentenregel

Agenten duerfen Sliderwerte nur verwenden, wenn sie aus API/Backend kommen. Sie duerfen diese Werte nicht frei berechnen.
