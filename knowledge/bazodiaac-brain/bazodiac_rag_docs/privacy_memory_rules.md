# Privacy and Memory Rules

## Zweck

Regeln fuer Speicherung und Umgang mit sensiblen Inhalten.

## Speichern erlaubt

- Gespraechszusammenfassung
- Topics/Tags
- Modus
- aktiver Planet
- semantische Hypothesenupdates
- Follow-up-Hooks
- Signatur-Events
- nicht-sensitive Reflexionsnotizen

## Nicht speichern

- Gesundheitsdaten
- intime sexuelle Details
- juristische Details
- finanzielle Details
- hochsensible private Informationen ohne Notwendigkeit
- therapeutische Diagnosen
- biografische Traumaannahmen

## Hypothesenstatus

Alle Muster bleiben Hypothesen, keine Diagnosen.

## Nutzerkorrektur

Wenn Nutzer widerspricht:

- nicht als Widerstand deuten
- Lesart schwaechen
- ggf. als `contradiction` oder `user_rejected` speichern

## Modusregeln

- Deep Dive: darf Hypothesen anreichern.
- Free Mode: nur vorsichtige Updates.
- Day Pulse: keine Hypothesenvalidierung.
- Fusion: keine Hypothesenvalidierung.
- Partner Match: keine Deep-Dive-Hypothesenvalidierung.
