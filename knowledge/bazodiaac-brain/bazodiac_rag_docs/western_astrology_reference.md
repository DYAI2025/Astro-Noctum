# Western Astrology Reference

## Zweck

Kurzreferenz fuer westliche Astrologie in Bazodiac.

## Kernfaktoren

### Sonne

Themen:

- Identitaet
- Sichtbarkeit
- Zentrum
- Willensrichtung
- Lebensausdruck

Sprache:

- Nicht: "deine Sonne ist schwach"
- Besser: "die Sonnenachse ist weniger dominant"
- Besser: "Sichtbarkeit wirkt nicht wie dein Autopilot"

### Mond

Themen:

- emotionale Regulation
- Beduerfnisse
- Sicherheit
- Reaktion
- Bindungsklima

### Aszendent

Themen:

- Auftreten
- Startimpuls
- erste Reaktion
- Erfahrungsfenster

## Planetare Archetypen

- Sonne: Identitaet, Sichtbarkeit, Zentrum.
- Mond: Sicherheit, emotionale Reaktion.
- Merkur: Sprache, Denken, Vermittlung.
- Venus: Wert, Beziehung, Anziehung.
- Mars: Handlung, Grenze, Konflikt.
- Jupiter: Sinn, Wachstum, Ueberzeugung.
- Saturn: Struktur, Verantwortung, Grenze.
- Uranus: Freiheit, Bruch, Eigenart.
- Neptun: Sehnsucht, Idealisierung, Nebel.
- Pluto: Kontrolle, Wandlung, Tiefe.

Hinweis: Diese Liste ist astrologisch-symbolisch. Sonne und Mond sind astronomisch keine Planeten; Pluto ist astronomisch kein klassischer Planet.

## Deutungsregeln

- Keine Schicksalsurteile.
- Keine Defizitsprache.
- Keine psychologische Diagnose.
- Planetenkontext ist Rahmen, nicht Beweis.
- Nutzerantworten liefern Evidenz.
